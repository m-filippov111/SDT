# Зачёт с оценкой — промежуточная аттестация

Промежуточная аттестация по дисциплине «Технологии разработки программного обеспечения» — **зачёт с оценкой в форме защиты сквозного командного программного проекта**. Это интегральный КИМ дисциплины: он подтверждает освоение всех индикаторов в целом и не дублирует отдельный модуль.

Аттестация проверяет: **PL-1.1** (уровень С), **PL-1.2, PL-1.3, SS-2.1, SS-2.2** (уровень Б).

## Как устроена оценка

Оценка распределена по трём контурам и накапливается в течение семестра, а не выставляется однократно на защите (100 баллов):

| Контур | Что оценивается | Баллы |
| --- | --- | :--: |
| Текущий | Лабораторные работы модулей 2–5; собственные артефакты репозитория | 30 |
| Рубежный | Три спринт-ревью командного проекта | 30 |
| Промежуточная аттестация | Защита: демонстрация и индивидуальные вопросы по коду | 40 |

К защите команда приходит с уже накопленной оценкой, а ментор — знакомый с проектом по спринт-ревью. Поэтому защита не повторяет доклад об архитектуре, а подтверждает работоспособность решения и личное понимание собственного кода каждым участником.
