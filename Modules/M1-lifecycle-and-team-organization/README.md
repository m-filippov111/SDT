# Модуль 1. Жизненный цикл ПО и организация командной разработки

## Описание модуля

Модуль посвящён основам организации командной разработки программного обеспечения. Студенты изучают модели жизненного цикла ПО, гибкие методологии (Agile, Scrum, Kanban), формализацию требований и постановку задач в команде, включая взаимодействие с ИИ-агентами.

## Содержание модуля

| Элемент                                                 | Содержание                                                                                                                                                  | Форма                        | Часы |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- | ---- |
| Занятие 1.1. Жизненный цикл ПО и методологии разработки | Каскадная и итеративные модели; Agile, Scrum, Kanban; роли в команде разработки                                                                             | Лекция                       | 2    |
| Занятие 1.2. Требования и постановка задач              | Формализация требований: цель, контекст, входы и выходы, критерии приёмки; декомпозиция и оценка задач; постановка задач исполнителю — человеку и ИИ-агенту | Лекция / Лабораторная работа | 6    |
| Самостоятельная работа по модулю 1                      | Формирование команд (3–5 человек); выбор темы проекта; составление бэклога с критериями приёмки по каждой задаче                                            | Самостоятельная работа       | 8    |
