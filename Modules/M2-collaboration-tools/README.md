# Модуль 2. Инструменты коллективной разработки

## Описание модуля

Модуль посвящён инструментам и практикам командной разработки программного обеспечения. Студенты осваивают командные модели ветвления в Git, организацию код-ревью через Pull Request, настройку CI/CD для автоматического тестирования, работу с Git Hooks для автоматизации проверок, а также учатся выстраивать эффективное взаимодействие с ИИ-ассистентами в рамках проектной команды.
