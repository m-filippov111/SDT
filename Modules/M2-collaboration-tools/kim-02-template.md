3. Создайте бэклог спринта на основе требований из Модуля 1.

**Результат:** Ссылка на доску в файле `docs/task-tracker.md`.

### Этап 3. Создание библиотеки промпт-шаблонов

Создайте библиотеку промпт-шаблонов для ИИ-агентов команды:

1. Промпт для генерации тестов (pytest)

**Результат:** Файл `docs/ai-prompts-library.md` с шаблонами.

### Этап 4. Автоматизация написания коммитов через ИИ

Настройте скрипт для автоматического создания commit message на основе изменений в коде:

**Задача:**

1. Напишите Python-скрипт, который:
   - Анализирует изменённые файлы (`git diff --staged`)
   - Отправляет изменения в ИИ (ChatGPT API или локально через Ollama)
   - Получает предложение для commit message
   - Выводит предложение пользователю для подтверждения
   - Создаёт коммит с подтверждённым сообщением

2. Настройте Git alias для быстрого использования:

```
git config --global alias.ai-commit '!python scripts/ai_commit.py'
```

3. Документируйте процесс использования и примеры сгенерированных коммитов.

**Результат:**

- Файл `scripts/ai_commit.py`
- Документация в `docs/ai-commit-setup.md`
- Примеры в `docs/ai-commit-examples.md`

**Пример реализации (упрощённый):**

```python
# scripts/ai_commit.py
import subprocess
import json
import openai  # или другой клиент

def get_staged_diff():
 result = subprocess.run(
     ["git", "diff", "--staged"],
     capture_output=True,
     text=True
 )
 return result.stdout

def generate_commit_message(diff):
 # Отправка diff в ИИ и получение commit message
 # Пример промпта
 prompt = f"""
 Based on the following git diff, generate a conventional commit message.
 Use format: <type>(<scope>): <subject>
 Types: feat, fix, docs, style, refactor, test, chore

 Diff:
 {diff}

 Return only the commit message.
 """
 # Отправка в ИИ
 response = openai.ChatCompletion.create(
     model="gpt-3.5-turbo",
     messages=[{"role": "user", "content": prompt}]
 )
 return response.choices[0].message.content

def main():
 diff = get_staged_diff()
 if not diff:
     print("No staged changes found.")
     return

 print("Generating commit message...")
 message = generate_commit_message(diff)
 print(f"\nSuggested commit message:\n{message}\n")
 confirm = input("Use this message? (y/n): ")
 if confirm.lower() == 'y':
     subprocess.run(["git", "commit", "-m", message])
     print("Commit created successfully!")
 else:
     print("Commit cancelled.")

if __name__ == "__main__":
 main()
```
