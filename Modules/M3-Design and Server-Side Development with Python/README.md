**Модуль 3. Проектирование и серверная разработка на Python**

Описание модуля

Модуль посвящён инструментам и практикам проектирования и серверной разработки на Python. Студенты осваивают полный цикл создания серверной части веб-приложения — от архитектурного проектирования до реализации API с подключением к базе данных, изучают принципы организации кода (слои приложения, пакеты, управление зависимостями), осваивают современный веб-фреймворк FastAPI для построения RESTful сервисов с валидацией данных, а также учатся работать с реляционными базами данных через ORM SQLAlchemy (модели, запросы, транзакции, пул соединений) и управлять изменениями схемы с помощью Alembic, включая диагностику и устранение типовых проблем производительности, таких как N+1 запросов. Итогом модуля является самостоятельная работа, в рамках которой студенты в командном формате реализуют первый спринт серверной части проекта, создавая рабочее API, модели данных и интегрируя хранилище, что закладывает основу для дальнейшей разработки полноценного приложения. А также учатся выстраивать эффективное взаимодействие с ИИ-ассистентами в рамках проектной команды.
