# Модуль 4. Качество программного обеспечения

## Описание модуля

Модуль посвящён обеспечению и оценке качества прикладного решения на Python. Студенты осваивают модульные и интеграционные тесты (pytest), фикстуры и покрытие, подключение проверок и тестов к CI-конвейеру, а также практики отладки, структурированного логирования и профилирования. Результаты модуля составляют содержание второго спринта командного проекта: покрытие ключевой логики тестами и взаимное код-ревью между командами.

## Место модуля в проекте

Практики качества, освоенные в этом модуле, входят в командный проект и демонстрируются на **втором спринт-ревью** (см. [проектную работу](../../Project/README.md)): тесты ключевой логики, работающий CI, результаты взаимного код-ревью. Индикатор PL-1.1 (уровень С) закрывается текущим контролем модуля и рубежным контролем спринта 2; итоговое подтверждение — на защите (см. [зачёт с оценкой](../../Exam/exam.md)).

Модуль опирается на инженерную обвязку модуля 2 (репозиторий, Pull Request, CI) и серверную часть модуля 3 (FastAPI, ORM): тесты и диагностики применяются к уже реализованному коду проекта, а не к учебным заглушкам.
