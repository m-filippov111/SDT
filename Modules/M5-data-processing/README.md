# Модуль 5. Обработка данных в приложении

## Описание модуля

Модуль посвящён подсистеме обработки данных прикладного решения. Студенты учатся обоснованно выбирать библиотеки обработки и визуализации данных под сформулированные требования (NumPy, Pandas, Matplotlib) и разрабатывать простые конвейеры обработки данных (ETL): извлечение, преобразование, загрузку, обработку ошибок и регламентный запуск. Результаты модуля составляют содержание третьего спринта командного проекта.

Подсистема данных, разработанная в этом модуле, входит в командный проект и демонстрируется на **третьем спринт-ревью** (см. [проектную работу](../../Project/README.md)).
