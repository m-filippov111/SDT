# Фонд оценочных средств по дисциплине «Технологии разработки программного обеспечения»

Этот репозиторий предназначен для открытого и воспроизводимого представления фонда оценочных средств (ФОС) по дисциплине «Технологии разработки программного обеспечения». Здесь объединены рабочая программа дисциплины, модель измерения результатов обучения, контрольно-измерительные материалы (КИМ), критерии оценивания, методические рекомендации и используемые образовательные ресурсы. Результаты обучения связываются с компетентностно-ролевой моделью в области искусственного интеллекта (КРМ версии 3.0).

## 1. О дисциплине

**Цель дисциплины.** Сформировать у обучающихся компетенции промышленной разработки программного обеспечения на Python в составе проектной команды: от постановки задач и организации совместной работы до тестирования, документирования и защиты работающего решения.

**Основные задачи.**

1. Сформировать умение разрабатывать, отлаживать и тестировать серверные прикладные решения на Python, оценивая их качество (PL-1.1, уровень С).
2. Сформировать умение обоснованно выбирать инструменты разработки на Python под требования прикладной системы обработки данных (PL-1.2, уровень Б).
3. Сформировать навыки разработки и поддержки простых конвейеров обработки данных (PL-1.3, уровень Б).
4. Сформировать навыки коммуникации в проектной команде: постановка задач людям и ИИ-агентам, фиксация договорённостей и критериев готовности (SS-2.1, уровень Б).
5. Сформировать умение распределять ответственность в команде и представлять результаты работы в понятном аудитории формате (SS-2.2, уровень Б).

**Структура и содержание.** Дисциплина состоит из 6 модулей: «Жизненный цикл ПО и организация командной разработки», «Инструменты коллективной разработки», «Проектирование и серверная разработка на Python», «Качество программного обеспечения», «Обработка данных в приложении», «Командный программный проект (сквозной)». Обучение включает лекции, лабораторные работы, самостоятельную работу и завершается зачётом с оценкой (защитой командного программного проекта).

**Пререквизиты и связи с другими дисциплинами.** Для освоения дисциплины требуются знания базового Python, библиотек обработки и визуализации данных, основ работы с Git, проектирования и подключения хранилища данных, формализации логики предметной области. Дисциплина является второй ступенью сквозной инженерной линии образовательной программы.

**Планируемые результаты обучения.** По завершении дисциплины обучающийся сможет:

- разрабатывать, отлаживать и тестировать серверные прикладные решения на Python, оценивая их качество;
- обоснованно выбирать инструменты разработки на Python под требования прикладной системы обработки данных;
- разрабатывать и поддерживать простые конвейеры обработки данных;
- эффективно коммуницировать в проектной команде, включая постановку задач людям и ИИ-агентам;
- распределять ответственность в команде и представлять результаты работы в понятном аудитории формате.

Полное описание приведено в [РПД](docs/rpd.md).

## 3. Контрольно-измерительные материалы

- [Модуль 1](Modules/M1-lifecycle-and-team-organization/README.md) — жизненный цикл ПО и организация командной разработки;
- [Модуль 2](Modules/M2-collaboration-tools/README.md) — инструменты коллективной разработки;
- [Модуль 3](Modules/M3-design-and-server-development/README.md) — проектирование и серверная разработка на Python;
- [Модуль 4](Modules/M4-software-quality/README.md) — качество программного обеспечения;
- [Модуль 5](Modules/M5-data-processing/README.md) — обработка данных в приложении;
- [Проектная работа](Project/README.md) — интегральный КИМ по нескольким результатам обучения;
- [Зачёт с оценкой](Exam/README.md) — промежуточная аттестация (защита командного проекта).

Каждый КИМ должен содержать назначение, проверяемые результаты, условия выполнения, материалы задания, формат сдачи, критерии и шкалу оценивания, правила использования внешних ресурсов и генеративного ИИ.
