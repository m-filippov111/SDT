# Методические указания преподавателям по оцениванию

Документ дополняет [процедуру аттестации](../../Exam/exam.md) и рубрики модулей: как переводить проценты рубрик в баллы, как фиксировать индивидуальный вклад и как разбирать апелляции.

## 1. Перевод процентов рубрики в баллы

Каждое средство контроля имеет максимальный балл (таблица «Распределение баллов по средствам контроля» в [exam.md](../../Exam/exam.md)). Балл за работу = процент по её рубрике × максимальный балл средства. Пример: лабораторная модуля 5 на 85 % рубрики = 0,85 × 4 = 3,4 балла. Если в модуле несколько лабораторных, балл модуля делится между ними поровну.

## 2. Зачем оценка распределена по трём контурам

60 из 100 баллов набираются в течение семестра (лабораторные, история репозитория, три спринт-ревью) и не восстанавливаются задним числом. Это делает невозможным сценарий «не работать весь семестр и воспроизвести результат за одну ночь», в том числе бездумной генерацией: к защите команда приходит с уже накопленной оценкой, а ментор знаком с проектом. Поэтому пропуск контрольных точек нельзя компенсировать только качеством финального продукта.

## 3. Фиксация индивидуального вклада

Вклад участника подтверждается тремя независимыми источниками: история репозитория (коммиты, pull request, код-ревью); матрица RACI и отчёты спринт-ревью; индивидуальные вопросы на защите. На каждом из трёх спринт-ревью вклад фиксируется отдельно — это основа индивидуальной оценки. Расхождение между источниками (например, объёмный код при неспособности объяснить его на защите) разбирается в пользу третьего источника.

## 4. Разведение контуров: без двойного учёта

Один и тот же артефакт не оценивается по одним и тем же критериям дважды. В **текущем контроле** по рубрике модуля оценивается индивидуальная лабораторная работа (качество кода). В **рубежном контроле** по рубрике спринт-ревью оценивается интеграция результата в продукт и вклад участника (организация работы, распределение задач, коммуникация). Рубрики проверяют разное.

## 5. Апелляции

- Несогласие с **фиксацией индивидуального вклада** подаётся и разбирается в течение семестра — на ближайшем спринт-ревью, пока результат подтверждается свежими артефактами репозитория и трекера.
- Апелляция по **процедуре и результатам промежуточной аттестации** подаётся в порядке, установленном локальными нормативными актами образовательной организации.
- Командная часть оценки (демонстрация, продукт) при разборе индивидуального вклада не пересматривается.

## 6. Пропуски контрольных точек

Уважительная причина — отработка в согласованный срок без штрафа; неуважительная — отработка в течение недели, повторный пропуск закрывает допуск к защите до отработки. Порядок при длительной болезни или академическом отпуске — по локальным нормативным актам образовательной организации.
