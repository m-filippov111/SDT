# Методические указания преподавателям по использованию ресурсов

Документ описывает, как подбирать и применять информационные ресурсы при разработке контрольно-измерительных материалов (КИМ). Каталог ресурсов размещён в разделе [`resources/`](../../resources/README.md); перечень основной и дополнительной литературы, интернет-ресурсов и программного обеспечения задан рабочей программой дисциплины ([`docs/rpd.md`](../../docs/rpd.md)).

## 1. Каталог ресурсов

Ресурсы сгруппированы по типам в разделе [`resources/`](../../resources/README.md):

| Тип | Назначение при разработке КИМ |
|---|---|
| [Учебники](../../resources/textbooks/README.md) | базовые и дополнительные учебные материалы |
| [Научные статьи](../../resources/papers/README.md) | современное состояние области и исследовательские задания |
| [Банки тестов](../../resources/test-banks/README.md) | текущий и промежуточный контроль |
| [Банки задач](../../resources/problem-banks/README.md) | практические, расчётные и кейсовые задания |
| [Датасеты](../../resources/datasets/README.md) | учебные и проектные данные |
| [Бенчмарки](../../resources/benchmarks/README.md) | сравнение методов и оценка качества |
| [Python-библиотеки](../../resources/software/python-libs/README.md) | программная реализация и автоматическая проверка |
| [LLM и промпты](../../resources/llm-prompts/README.md) | генерация, анализ и оценивание с применением БЯМ |
| [Прочее](../../resources/other/README.md) | справочники, сервисы и иные материалы |

При добавлении ресурса выбирайте раздел по типу материала; в раздел «Прочее» помещайте только то, что нельзя содержательно отнести к другим разделам.

## 2. Единая карточка ресурса

Каждый ресурс описывается по единой карточке — это делает подбор воспроизводимым и позволяет проверять актуальность:

| Поле | Что указать |
|---|---|
| Название | официальное название |
| Тип | учебник / статья / датасет / библиотека / сервис / промпт |
| Аннотация | 1–3 предложения |
| Связанные КИМ | относительные ссылки на КИМ, где ресурс применяется |
| Доступ | внутренняя или внешняя ссылка |
| Лицензия | условия использования |
| Дата проверки | ГГГГ-ММ-ДД |

Поле **«Связанные КИМ»** обязательно: оно связывает ресурс с конкретным заданием и позволяет от КИМ переходить к его ресурсам и обратно. Ссылки указывайте относительными, чтобы они сохранялись при клонировании репозитория.

## 3. Подбор ресурсов под КИМ

Каждый КИМ содержит раздел о правилах использования внешних ресурсов и генеративного ИИ, а его задание опирается на конкретные материалы (датасеты, библиотеки, шаблоны). При подборе ресурса под задание руководствуйтесь требованиями:

- **устойчивость ссылки** — ресурс должен быть доступен по стабильному адресу; для внутренних материалов используйте относительные ссылки внутри репозитория;
- **корректные условия использования** — у внешнего материала должна быть указана лицензия или условия, допускающие учебное применение;
- **связь с проверяемым результатом** — ресурс должен работать на индикатор, проверяемый КИМ, а не добавляться «для полноты»;
- **актуальность** — дата проверки фиксируется в карточке и обновляется при пересмотре КИМ.

Ресурс, для которого нельзя указать устойчивую ссылку и корректные условия использования, в КИМ не включается.

## 4. Литература, интернет-ресурсы и программное обеспечение

Перечни, заданные рабочей программой дисциплины, — опора при разработке заданий:

- **Основная и дополнительная литература** — раздел 9 РПД ([`docs/rpd.md`](../../docs/rpd.md)); используйте как источник теоретической базы заданий и для раздела «литература» карточек ресурсов.
- **Интернет-ресурсы** (электронно-библиотечные системы, научные библиотеки) — раздел 10 РПД; применяйте для исследовательских заданий и поиска первоисточников.
- **Программное обеспечение** (Python 3, система контроля версий Git и веб-сервис хостинга репозиториев, StarUML и др.) — раздел 12 РПД; на нём строятся практические и лабораторные КИМ, а Git-репозиторий служит единой средой учебной деятельности и автоматической проверки.

## 5. Ресурсы для работы с генеративным ИИ

Применение ИИ-ассистентов в дисциплине не запрещается, а регламентируется: оно является частью содержания индикатора SS-2.1. Раздел [LLM и промпты](../../resources/llm-prompts/README.md) предназначен для ресурсов генерации, анализа и оценивания с применением больших языковых моделей — модели, промпт-шаблоны и правила верификации результатов. При включении таких ресурсов в КИМ правила применения генеративного ИИ формулируйте явно: что допускается делать с помощью ИИ, как проверяется результат и по каким артефактам оценивается понимание обучающимся итогового решения.
