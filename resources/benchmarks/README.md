### Рекомендуемые метрики для проектов студентов

| Тип проекта       | Метрика                  | Целевое значение              |
| ----------------- | ------------------------ | ----------------------------- |
| REST API          | Запросов в секунду (RPS) | > 1000 для простых эндпоинтов |
| REST API          | Средняя latency          | < 100 мс                      |
| База данных (ORM) | Время выполнения запроса | < 50 мс для типовых запросов  |
| Тесты             | Время выполнения тестов  | < 5 минут для CI              |
| Покрытие кода     | Минимальное покрытие     | > 80%                         |
| CI/CD             | Время сборки             | < 5 минут                     |
| ETL-конвейер      | Время обработки          | < 1 минуты на 1000 записей    |
| Docker-образ      | Размер образа            | < 500 MB                      |
