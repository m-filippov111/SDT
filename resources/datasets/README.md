### Рекомендации для проектов студентов

| Тип проекта              | Рекомендуемый датасет      | Объём             | Сложность |
| ------------------------ | -------------------------- | ----------------- | --------- |
| ETL-конвейер + отчёты    | Sales Dataset / E-Commerce | ~10K-100K записей | Низкая    |
| REST API + ORM           | Students Performance       | ~1K-10K записей   | Низкая    |
| ETL + визуализация       | Weather Dataset            | ~10K-50K записей  | Средняя   |
| Большие данные           | NYC Taxi Dataset           | >1M записей       | Высокая   |
| Проект с ML              | Titanic / Iris             | <1K-10K записей   | Низкая    |
| Рекомендательная система | MovieLens                  | ~100K-1M записей  | Средняя   |
